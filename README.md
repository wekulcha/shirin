# Ширин

Отдельное приложение для заказов напитков «Ширин» и «Сады Востока» торговыми агентами в Узбекистане. Основа: KULCHA Market; происхождение и исходный commit см. `docs/source-audit.md`.

Разработка ведётся в `develop`; `main` содержит начальную основу. Интеграция Market находится в соседнем worktree `market-shirin-integration`.

Инструкции запуска и результаты проверок дополняются по мере реализации.
